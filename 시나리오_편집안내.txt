==============================================================
 AI 이후의 인생게임 — 시나리오 편집 안내 (에디터용)
==============================================================

이 게임의 모든 이야기·선택지·게이지 변화는 "시나리오.txt" 한 파일에 있습니다.
HTML(labor-life-game.html)은 그 파일을 읽어서 게임을 만듭니다.
HTML 안의 코드는 건드릴 필요가 없습니다.


--------------------------------------------------------------
 0. 파일 연결 방법 (셋 중 하나)
--------------------------------------------------------------

 A) 같은 폴더에 두고 로컬 서버로 열기 (가장 편함, 수정→새로고침이면 바로 반영)
    1. labor-life-game.html 과 시나리오.txt 를 같은 폴더에 둡니다.
    2. 그 폴더에서 터미널(명령 프롬프트)을 열고:
         python -m http.server 8000
    3. 브라우저에서  http://localhost:8000/labor-life-game.html  을 엽니다.
    4. 시나리오.txt 를 고치고 저장 → 브라우저 새로고침(F5).
    * HTML 파일을 그냥 더블클릭(file://)해서 열면 브라우저 보안 때문에
      txt를 자동으로 못 읽습니다. 그때는 B 방법을 쓰세요.

 B) 파일을 끌어다 놓기 / 불러오기 버튼
    표지 화면 아래 "시나리오 파일 불러오기"를 누르거나,
    시나리오.txt 를 게임 화면 위에 드래그해서 놓으면 바로 적용됩니다.
    (브라우저에 저장되므로 새로고침해도 유지됩니다.
     원래대로 돌리려면 표지의 "파일 다시 읽기 / 내장으로"를 누르세요.)

 C) 클로드 아티팩트(온라인 링크)에서 쓸 때
    시나리오.txt 를 고쳐서 클로드에게 주면 함께 다시 올려 드립니다.
    또는 B처럼 끌어다 놓아도 됩니다.

 표지 화면 맨 아래에 "시나리오 출처"와 "노드/선택지 수"가 찍힙니다.
 형식이 틀리면 거기에 빨간 글씨로 "몇 행이 왜 틀렸는지" 나옵니다.


--------------------------------------------------------------
 1. 전체 구조
--------------------------------------------------------------

 # 으로 시작하는 줄 = 주석 (게임에서 무시)
 빈 줄은 자유롭게 넣어도 됩니다.

 [설정]        전체 숫자 설정 (출생년도, 시작 게이지, 사망 나이 공식 …)
 [프롤로그]    AI 도입 이전 연표 (선택지 없이 한 줄씩 넘김)
 [노드 이름]   중대 결정 카드 하나 = 노드 하나  (여러 개)
 [엔딩 이름]   엔딩 다섯 개 (관계 / 자아실현 / 도덕 / 생산성 / 동점)


--------------------------------------------------------------
 2. 게이지 (네 가지 가치, 각각 0~게이지최대)
--------------------------------------------------------------

   자아실현   생산성   도덕   관계

 게이지 변화는 이렇게 씁니다 (쉼표로 구분, +/- 숫자):
   관계 +2, 생산성 -1
   도덕 +1
   (비워 두면 변화 없음)

 마지막에 가장 높은 게이지가 엔딩을 정합니다.
 1등이 둘 이상 같으면 → [엔딩 동점]

 ▸ 재산 (다섯 번째 수치, 단위 만원)
   네 가치 게이지와 별개로 '지금 돈이 얼마나 있는지'를 보여주는 수치입니다.
   엔딩을 정하는 데는 쓰이지 않고, HUD 나이 옆과 엔딩 화면의 타일·'남긴 것'에 나옵니다.
   [설정] 시작재산 = 12000        ← 만원 단위 (12000 = 1억 2,000만원)
   선택지 게이지 칸에 같이 적습니다. 돈과 상관없는 선택지엔 안 적어도 됩니다.
     1. 계약서에 서명한다. | 생산성 +3, 재산 +7000 | 다음 n6
     2. 간병인을 고용한다. | 관계 +3, 재산 -6000 | 다음 n11
   화면에는 1억 2,000만 / +7,000만 식으로 자동 변환되어 표시됩니다. 마이너스(빚)도 됩니다.
   시작재산을 지우고 어떤 선택지에도 재산을 안 적으면 재산 표시 자체가 사라집니다.



 ▸ 장례식 (엔딩 화면 · 재산 × 관계)
   엔딩 추모관의 장례식장 그림과 "빈소/조화/부고/조문객" 표, 본문 끝 두 문장이
   재산 등급과 관계 게이지에 따라 달라집니다.
   - 재산 등급: [설정] 재산구간 = 5000, 15000, 30000
       → 5,000만 미만 조촐 · 1억 5천 미만 보통 · 3억 미만 넉넉 · 그 이상 호화
       (벽·제단 크기·국화 수·조화 개수·샹들리에가 등급을 따릅니다)
   - 조문객 수: [설정] 조문구간 = 6, 12   ← 관계 게이지 기준 적음/보통/많음
       (그림 속 조문객 인원과 "조문객 n명"은 관계 게이지에서 계산)
   - 문장 바꾸기 (선택, 없으면 기본 문장):
       장례문구_조촐 = …   장례문구_보통 = …   장례문구_넉넉 = …   장례문구_호화 = …
       조문문구_적음 = …   조문문구_보통 = …   조문문구_많음 = …
       빈소_조촐 = …       빈소_보통 = …       빈소_넉넉 = …       빈소_호화 = …
   돈은 많은데 관계가 낮으면 '호화 빈소에 조문객 둘' 같은 장면이 자동으로 나옵니다.


--------------------------------------------------------------
 3. [설정] 항목
--------------------------------------------------------------

 현재 시나리오는 38세부터 77세까지 3년 간격(38·41·44 … 77)으로 카드가 있고,
 44세에서 세 경로(관리자/선생/현장)로 갈라져 47·50·53·56세를 따로 지난 뒤 59세에 합류합니다.
 중간에 카드를 끼우거나 빼도 되지만, 나이는 앞 카드보다 커야 합니다.


 출생년도 = 1999          → 나이 옆에 표시되는 연도 계산용 (35세 = 2034년)
 시작나이 = 35            → 게임(선택)이 시작되는 나이. HUD 연표의 왼쪽 끝
 연표끝 = 85              → HUD 연표의 오른쪽 끝
 시작노드 = n1            → 첫 번째 중대 결정 카드의 이름
 게이지최대 = 20          → 게이지 상한 (결정 횟수가 많으면 10은 금방 꽉 차서 동점이 늘어남)
 시작게이지 = 자아실현 4, 생산성 4, 도덕 5, 관계 4
 사망기본 = 79            → 사망 나이 = 사망기본 + 관계게이지 × 사망관계배수
 사망관계배수 = 0.5          (더한 값은 사망최대추가를 넘지 않음)
 사망최대추가 = 4          → 지금 설정이면 79~83세
 표지문구 = …              → 표지 화면의 소개 문단
 소개 = …                  → 인사 기록 카드의 설명 문장
 마지막질문 = …            → 엔딩 맨 아래 큰 질문
 마지막부제 = …            → 그 밑의 한 줄
 지도 = 27:s0:休, 28:s1:알, …   → 인생 지도(한 칸 = 1년)의 색 구간
          나이:색:글자  — 그 나이부터 그 색, 글자는 그 해 칸에만 표시
          색 이름: s0 무직(어둡게) · s1 일하는 시기 · s3 AI 도입 · s2 AI 이후 경로 · s4 퇴직 이후
 지도범례 = …              → 인생 지도 아래 글자 설명


--------------------------------------------------------------
 4. [프롤로그]  한 줄 = 한 카드
--------------------------------------------------------------

   나이 | 문장 | 가치 표시 | 현재

   27 | 만기전역, 대졸 … |
   28 | 떠밀려 시작한 알바 … | 노동의 가치 ① 자아실현
   35 | 회사에 AI가 들어온다 … | 노동의 가치 ④ ? | 현재

 - 가치 표시는 비워도 됩니다 (끝의 | 는 있어도 없어도 됨).
 - 마지막 줄에 "현재"를 붙이면 분홍색으로 강조됩니다.


--------------------------------------------------------------
 5. [노드 이름]  중대 결정 카드
--------------------------------------------------------------

 [노드 n1]
 나이 = 35                         ← 숫자, 또는 "사망" (마지막 날 카드)
 장 = 제4장 · AI 이후                ← 카드 위 작은 레이블 (자유 문구)
 제목 = 학습 데이터
 본문 =
 문단 1
 문단 2
 "따옴표 안"은 대사로 표시됩니다
 {중괄호 안}은 모노 글꼴 칩(시스템 이름 등)으로 표시됩니다
 @경로 감독자 | 이 줄은 경로가 '감독자'일 때만 보입니다
 @엔딩 관계 | 이 줄은 현재 1등 게이지가 '관계'일 때만 보입니다
 멈춤 = 청중에게 던지는 질문          ← 있으면 분홍 "잠시 멈춤" 상자가 뜸 (없으면 줄 삭제)
 자료 = 인용할 자료 한 줄            ← 있으면 선택지 위에 모노 글꼴로 표시 (없으면 줄 삭제)
 선택 =
 1. 선택지 문장 | 게이지 변화 | 다음 n2
 2. 선택지 문장 | 게이지 변화 | 다음 n2 | 표시 hid
 3. 선택지 문장 | 게이지 변화 | 다음 a1 | 경로 감독자

 선택지 한 줄의 칸 (| 로 구분):
   1칸  화면에 보이는 문장
   2칸  게이지 변화  (예: 관계 +2, 생산성 -1 / 비워도 됨)
   3칸  다음 노드    "다음 n2"   → 엔딩으로 보내려면 "다음 끝"
   그 뒤 (선택)
        "표시 이름"  → 엔딩 화면 '기록' 칸에 남는 표시 (예: 표시 shared)
        "경로 이름"  → 이후 HUD에 "경로 · 이름"이 붙고, @경로 줄의 조건이 됨

 규칙
 - 노드 이름은 영문/숫자가 안전합니다 (n1, a1, b2, ending1 …). 중복 금지.
 - 선택지는 1개 이상, 숫자키로 고르므로 9개 이하 권장.
 - 선택지가 1개뿐이면 Enter/Space로도 넘어갑니다.
 - "다음"에 적은 노드가 없으면 표지에 오류로 뜹니다.
 - 나이는 앞 노드보다 커야 HUD의 나이가 흘러가는 연출이 자연스럽습니다.
 - 나이 = 사망  인 노드는 하나만 두세요(마지막 병실 장면). 나이는 사망 공식으로 계산됩니다.


--------------------------------------------------------------
 6. [엔딩 이름]  다섯 개 모두 있어야 함
--------------------------------------------------------------

 [엔딩 관계]          ← 관계 / 자아실현 / 도덕 / 생산성 / 동점
 제목 = 찾아오는 사람   ← 추모관의 큰 분홍 제목
 조건 = 관계 최고       ← 카드 위 레이블·엔딩 지도에 표시되는 설명
 그림 = l2             ← l1 집과 나무 · l2 교실 · l3 들판 · l4 밤의 집 · room 방
 묘비 = 사람들이 찾아오던 사람.   ← 손글씨 한 줄 + 추모 카드 한 줄
 본문 =
 문단 1
 문단 2


--------------------------------------------------------------
 7. 자주 하는 편집 예시
--------------------------------------------------------------

 ▸ 선택지 하나의 수치만 바꾸기
   1. 전부 넘긴다. … | 생산성 +2, 자아실현 -1 | 다음 n2
   →                | 생산성 +3, 자아실현 -2 | 다음 n2

 ▸ 분기 하나 새로 끼우기 (45세와 50세 사이에 48세 카드)
   1) 새 노드를 추가:
      [노드 a2b]
      나이 = 48
      장 = 제5장 · 감독자
      제목 = 새 사건
      본문 =
      …
      선택 =
      1. … | 관계 +1 | 다음 n4
      2. … | 생산성 +1 | 다음 n4
   2) 앞 노드(a2)의 선택지에서 "다음 n4"를 "다음 a2b"로 바꿉니다.

 ▸ 엔딩 글만 바꾸기 → [엔딩 …]의 제목/묘비/본문만 수정

 ▸ 시작 게이지를 바꿔 엔딩 분포를 조정하기
   [설정] 시작게이지 = … 의 숫자를 바꿉니다.
   (현재 값은 무작위 20만 회 플레이 기준으로 다섯 엔딩이 13~26%로 나오도록 맞춘 값)

 ▸ 표지의 "선택지 n개 / 엔딩 n개 / 35~83세" 숫자는 파일을 읽어 자동 계산됩니다.


--------------------------------------------------------------
 8. 문제가 생기면
--------------------------------------------------------------

 - 표지 아래 빨간 "시나리오 오류" 상자에 몇 행이 왜 틀렸는지 나옵니다.
 - 오류가 있어도 게임은 켜지지만, 없는 노드로 가면 엔딩 화면으로 떨어집니다.
 - 파일은 UTF-8로 저장하세요 (메모장이라면 "다른 이름으로 저장 → 인코딩 UTF-8").
 - 한글 "｜"(전각)이 아니라 반각 "|"를 써야 칸이 나뉩니다.
