# AI 이후의 인생게임

> (전) 무직백수의 살아남기 시즌 2 — "노동의 가치" 발표용 인생 시뮬레이션

38세, 반도체 중소기업 사무직. 회사에 AI가 들어온 뒤 '동료와 함께하는 일'을 택한 지 1년.
그 다음부터 눈을 감는 날까지 3년에 한 번씩 선택을 내리고, 선택할 때마다 네 가지 가치의 게이지가 움직입니다.

**자아실현 · 생산성 · 도덕 · 관계** — 마지막에 가장 높이 쌓인 가치가 엔딩을 정합니다.
재산은 따로 쌓이며, 장례식의 모습(빈소·조화·조문객)이 재산과 관계에 따라 달라집니다.

## 플레이

- 🎮 **[바로 플레이하기](https://pilgrim2412.github.io/life-game-kimbeaksu/)** (GitHub Pages)
- 키보드: 숫자키로 선택 · Enter/Space 다음 · R 처음부터 · M 엔딩 지도
- 발표 중에는 "게이지 변화 보기"를 꺼 두고 진행하다가, 결과 설명 때 켜면 각 선택지의 ± 수치가 드러납니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 본체 (엔진 + 디자인). 시나리오 텍스트는 들어 있지 않음 |
| `시나리오.txt` | **모든 이야기·선택지·게이지 변화·재산·장례식 설정** — 이 파일만 고치면 게임이 바뀜 |
| `scenario.txt` | 위 파일의 사본 (한글 파일명을 못 읽는 환경용) |
| `시나리오_편집안내.txt` | 시나리오 파일 형식 설명서 |

### 시나리오 고치기

`시나리오.txt`를 열어 문장이나 숫자를 바꾸고 저장하면 됩니다. 형식은 이렇게 생겼습니다.

```
[노드 n1]
나이 = 38
장 = 제4장 · 동료를 택한 뒤
제목 = 평가
본문 =
매 년마다 찾아오는 ... {승인 처리 건수}만을 실적으로 판단한다는 것이였다.
선택 =
1. 지표에 맞춘다. | 생산성 +2, 관계 -1, 재산 +600 | 다음 n2
2. 그대로 쓴다. | 자아실현 +2, 생산성 -1, 재산 -300 | 다음 n2
```

- 선택지 한 줄 = `문장 | 게이지 변화 | 다음 노드 | (표시/경로)`
- 분기를 늘리려면 `[노드 새이름]`을 추가하고 앞 노드의 `다음`을 거기로 돌립니다.
- 형식이 틀리면 표지 화면 아래에 "몇 행이 왜 틀렸는지" 빨간 글씨로 나옵니다.
- 자세한 설명은 `시나리오_편집안내.txt`.

### 로컬에서 돌리기

`index.html`을 더블클릭해서 열면 브라우저 보안 때문에 `시나리오.txt`를 자동으로 못 읽습니다(내장 복사본으로 실행됨).
수정한 시나리오를 바로 보려면 폴더에서 간단한 서버를 띄우세요.

```
python -m http.server 8000
# → http://localhost:8000/
```

또는 게임 화면에 `시나리오.txt`를 끌어다 놓거나, 표지의 "시나리오 파일 불러오기"를 누르면 됩니다.
